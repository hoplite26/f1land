## Что сделано в этой итерации

### Оболочка, Telegram, общий UI-kit
- Таб-бар скрывается на экране пула (`route.name === 'pool'`), вместо него нижний док ставки в зоне большого пальца.
- Вызовы Telegram WebApp API проверяют версию (`isVersionAtLeast`): больше нет предупреждений «not supported in version 6.0» в консоли; хаптика и BackButton включаются только с 6.1+.
- Стек обработчиков кнопки «Назад» Telegram: открытая шторка или диалог закрывается первым (`pushOverlayBack` в `src/telegram/sdk.ts`).
- `Sheet`: перетаскивание только за шапку (тело прокручивается свободно), закрытие по Escape и кнопке «Назад» Telegram, фокус переходит в шторку и возвращается обратно, кнопка закрытия 44×44.
- `SwipeConfirm`: `touch-action: pan-y` (страница прокручивается, когда палец на свайпере), подсказка-«толчок» ручки при простом тапе, фокус-кольцо, подтверждение через Enter/Space.
- Тосты: закрываются смахиванием, нажатие на действие тоже закрывает тост, вместо захардкоженных «Retry/Close» теперь i18n.
- `Segmented`: высота 40 px, подписи не вылезают за «пилюлю» («Открытые» на «Моих пулах»).
- Компактные `.chip`, `.icon-btn`, `.help__btn` получили невидимую зону нажатия ≥ 44 px.
- `<html lang>` следует языку интерфейса (корректные переносы и чтение экранными дикторами).

### Флоу прогноза (Pool / MyPools / `src/ui/bet/*`)
- Липкий нижний док ставки: исход + коэффициент, сумма, потенциальная выплата, свайп-подтверждение; когда исход не выбран, показывается подсказка; для закрытых, рассчитываемых и рассчитанных пулов вместо CTA показывается статус.
- Коэффициент у исходов без ставок: вместо «50,00x» везде «50x макс.» (`MULT_CAP` в `src/ui/bet/parts.tsx`; семантика `poolEngine` не менялась).
- Исправлены обрезанные заголовки пула, чипы «Другие исходы», единица в вопросе F1-M08 («…эталона 1:27,430 мс?»), красный «Закрыт» для обычного закрытого пула.
- Новый словарь `src/i18n/dicts/pool.ts`, правки текстов рынков в `src/domain/markets/i18n.ts` и `src/app/poolText.ts`.

### Контентные экраны (Home, Races, Leaderboard, Profile, Rewards, History, Wallet, Settings, Driver, Circuit)
- Главная: убраны обрезания в hero (кнопка хронометража, слоган, плашка пула, название трассы).
- Лидерборд: вместо «Вы в топ-100% игроков» при 0 очков приглашение сделать первый прогноз.
- Бейджи: без переносов посреди слова.
- История: ряд фильтров стал явным скроллером.
- Русские тексты без лишнего английского («Кошелёк DEMO», «Вернуться в Live» и т. п.).

### Live и 3D
- **Синхронизация с трансляцией**: найдена причина 30+ секунд экрана «Синхронизация…». Цикл догоняния в `src/demo/runner.ts` не мог израсходовать остаток меньше шага `SIM_DT` и крутился до конца бюджета кадра; в `replayToEnd` то же самое давало бесконечный цикл. Оба места исправлены.
- Пока идёт синхронизация, вместо «Сейчас нет открытых пулов» показывается состояние загрузки.
- Трасса в обзорной камере: неоновый контур трассы (`src/three/track/neonTrace.ts`), более редкая дымка для высоких камер.
- Камеры (`cameraRig.ts`): учёт области, закрытой UI (view offset), TV-камера на длинном объективе (машина ≈ ⅓ ширины кадра), мягкий переход с общего плана.
- Подпись режима камеры больше не налезает на полосу хронометража.
- Шейдеры компилируются заранее (`KHR_parallel_shader_compile`, где доступно), чтобы не было фризов в первых кадрах.
- Инструменты в `dev/`: `sync-probe.mjs` (время до синхронизации), `profile-sync.mjs` (CPU-профиль), `catchup.perf.ts` + `vitest.perf.config.ts`, `vite.nohmr.config.ts`.

## Как запускать

```bash
pnpm install
pnpm dev            # http://localhost:5173
pnpm typecheck && pnpm test && pnpm build
pnpm e2e            # собирает прод-сборку и гоняет Playwright (Chrome: CHROME_PATH или /usr/local/bin/google-chrome)
node dev/shot-scene.mjs --dir /tmp/shots --quality medium --shots "director:12000,tv:5000,overview:5000" --full
node dev/sync-probe.mjs --render 3d   # время до синхронизации Live
```

В dev-режиме доступны хэндлы `window.__nav`, `__live`, `__settings`, `__pools`, `__scene` для скриптовых скриншотов.
